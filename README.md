# Мой университет

Личный сервис для планирования самообучения: дисциплины, семестровое расписание с учётом Google Календаря, занятия с Помодоро, итоги и статистика. Работает локально на твоём ПК.

## Запуск

Нужен Node.js 24 или новее.

```bash
npm install
npm run dev
```

Интерфейс — http://localhost:5173, сервер — http://localhost:4100.

## Команды

| Команда             | Что делает                                        |
| ------------------- | ------------------------------------------------- |
| `npm run dev`       | запускает сервер и интерфейс                      |
| `npm run check`     | линтер, форматирование, проверка типов, все тесты |
| `npm test`          | только тесты                                      |
| `npm run check:env` | проверяет ключи Google в `.env`, не показывая их  |
| `npm run format`    | выравнивает форматирование кода                   |
| `npm run simulate`  | печатает расписание тестовых сценариев таблицей   |

Свои дисциплины и календарь можно прогнать через симулятор: скопируй [engine/sim/semester.example.json](engine/sim/semester.example.json), поправь и запусти:

```bash
npm run simulate -- --file engine/sim/semester.example.json
```

Флаг `--details` печатает все занятия семестра.

## Как пользоваться

Открой http://localhost:5173. При первом запуске — мастер: время для учёбы и неудобное время, Google Календарь, дисциплины (с целью и метриками), семестр. Дальше — вкладки «Сегодня» (занятие с таймером Помодоро и итог), «Расписание», «Решения» (вопросы сервиса), «Дисциплины», «Семестр», «Статистика», «Настройки».

## Тестовый экземпляр

Чтобы проверить интерфейс, не трогая настоящую базу и Google:

```bash
node scripts/test-instance.mjs
```

Интерфейс — http://localhost:5174, база — временная, часы перематываются запросом `POST /api/dev/clock` с `{"iso": "2026-10-27T12:00:00+03:00"}`.

## Структура

```
engine/   движок расписания: чистая логика + тесты
server/   локальный сервер: база, Google Календарь, фоновые проверки
web/      интерфейс
docs/     методология, план, решения, инструкции
```
