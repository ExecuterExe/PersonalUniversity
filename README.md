# Мой университет

Личный сервис для планирования самообучения: дисциплины, семестровое расписание с учётом Google Календаря, занятия с Помодоро, итоги и статистика. Работает локально на твоём ПК.

## Запуск

Нужен Node.js 24 или новее. Один раз:

```bash
npm install
npm run app:install
```

На рабочем столе появится ярлык «Мой университет», а сервис будет сам открываться на «Сегодня» при входе в Windows. Ярлык запускает сервер в фоне (без окна), если он ещё не работает, и открывает http://localhost:4100 в браузере. Напоминаний и уведомлений нет.

Автозапуск и ярлык включаются и выключаются в «Настройках» → «Запуск». Без автозапуска: `npm run app:install -- --no-autostart`.

Для разработки — `npm run dev` (интерфейс на http://localhost:5173 с горячей перезагрузкой). Перед этим останови фоновый сервис: `npm run app:stop`.

## Команды

| Команда                 | Что делает                                        |
| ----------------------- | ------------------------------------------------- |
| `npm run app`           | открывает сервис (запустит сервер, если нужно)    |
| `npm run app:stop`      | останавливает сервер, работающий в фоне           |
| `npm run app:install`   | ярлык на рабочем столе и автозапуск с Windows     |
| `npm run app:uninstall` | убирает ярлык и автозапуск                        |
| `npm run dev`           | режим разработки: сервер и интерфейс              |
| `npm run check`         | линтер, форматирование, проверка типов, все тесты |
| `npm test`              | только тесты                                      |
| `npm run check:env`     | проверяет ключи Google в `.env`, не показывая их  |
| `npm run format`        | выравнивает форматирование кода                   |
| `npm run simulate`      | печатает расписание тестовых сценариев таблицей   |

Свои дисциплины и календарь можно прогнать через симулятор: скопируй [engine/sim/semester.example.json](engine/sim/semester.example.json), поправь и запусти:

```bash
npm run simulate -- --file engine/sim/semester.example.json
```

Флаг `--details` печатает все занятия семестра.

## Как пользоваться

Открой ярлык «Мой университет». При первом запуске — мастер: время для учёбы и неудобное время, Google Календарь, дисциплины (с целью и метриками), семестр. Дальше — вкладки «Сегодня» (занятие с таймером Помодоро и итог), «Расписание», «Решения» (вопросы сервиса), «Дисциплины», «Семестр», «Статистика», «Настройки».

Особые случаи:

- **Опыт, звания и награды** — раздел «Прогресс»: за новый сохранённый итог занятия с хотя бы минутой чистой учёбы начисляется 100 опыта один раз. Всего 50 уровней; следующее звание раскрывается при повышении. В профиле можно оставить любимое открытое звание или показывать последнее автоматически. Старые итоги не начисляют опыт задним числом, пропуски ничего не отнимают. Общий опыт и заработанные награды сохраняются между семестрами и при их удалении.
- **Приятный перерыв после учёбы** — открой кнопку «Настройки» в «Прогрессе» и настрой свой набор наград (до 30 включённых). После занятия предлагаются до двух случайных разных вариантов; выбери один сейчас или позже в разделе «Награды». Награду можно оставить на вечер и вручную отметить использованной. Переименование и отключение наград меняет только будущие предложения.
- **Отключение и удаление наград** — общий переключатель в карточке «Твои приятные награды» убирает предложения после занятий и скрывает копилку. Опыт и слова продолжают работать; уже заработанное сохраняется. Кнопка корзины удаляет пункт из набора будущих наград. Проценты для приятных наград не задаются.
- **Коллекция качеств** — 500 положительных слов. У каждого нового занятия с опытом независимый шанс 50% получить одно новое слово; повторов нет. Результат сохраняется вместе с итогом, поэтому обновление страницы и повторная отправка не меняют бросок. Коллекция доступна в «Прогрессе», в ней есть поиск. Находки можно отключить отдельно, собранные слова сохранятся. Старые занятия не получают слова задним числом.
- **Вопрос следующему себе** — необязательное поле в итоге занятия. Покажется перед следующим занятием той же дисциплины и в режиме погружения. Если в новом итоге вопрос не записан, прежний больше не повторяется. Вопросы сохраняются в «Практике» и экспорте.
- **Дисциплина больше не нужна** — открой её карточку в «Дисциплинах» и нажми «Удалить». Карточка и источники исчезнут из библиотеки, включая архив, после подтверждения. Итоги прошлых занятий сохранятся в «Практике» и экспорте; прошлые события Google не меняются. Если дисциплина связана с текущим семестром или черновиком, карточка объяснит, почему удаление пока недоступно. После завершения семестра её можно удалить.
- **Нужно практическое задание по изученному** — открой «Практику», найди тему поиском, выбери последнее занятие или отметь нужные итоги из одной либо нескольких дисциплин. Фильтр «Выбранные» показывает отмеченные занятия, выбор сохраняется между страницами и дисциплинами. Настрой формат, время и сложность справа, затем собери и скопируй промпт в чат с ИИ. Полный текст открывается кнопкой «Посмотреть и изменить текст»; ручные правки сохраняются при сворачивании. В инструкции предусмотрены постепенные подсказки при затруднениях и полное решение только по явной просьбе. Сервис собирает промпт локально, без отправки записей в ИИ.
- **Хочешь составить семестр заново** — в «Семестре» или «Настройках» нажми «Удалить семестр» и подтверди. Удалятся все занятия семестра, их итоги, прогресс и связанные события в Google Календаре, включая прошлые и перенесённые. Дисциплины, источники и общие настройки сохранятся. Если Google недоступен, восстанови подключение и повтори удаление: до его завершения семестр останется в приложении.
- **Компьютер уснул или выключился во время занятия** — таймер встаёт на паузу с того момента, время сна в учёбу не идёт. Если ты занимался по книге, нажми «Я занимался — засчитать». Пока идёт занятие и открыта его страница, экран не гаснет.
- **Время занятия вышло** — таймер встаёт на паузу и предлагает записать итог или продолжить сверх плана. Ожидание ответа не входит в учёбу, в том числе при закрытой странице. При продолжении запланированный интервал в календаре сохраняется.
- **Другой часовой пояс на компьютере** (поездка) — расписание остаётся в поясе из настроек, сверху появляется подсказка, сколько там сейчас.

Если что-то не запускается — журнал сервера лежит в `data/logs/server.log`. После обновления кода интерфейс пересоберётся сам при следующем запуске ярлыка; если сервер уже работает — `npm run app:stop`, потом снова ярлык.

## Тестовый экземпляр

Чтобы проверить интерфейс, не трогая настоящую базу и Google:

```bash
node scripts/test-instance.mjs
```

Интерфейс — http://localhost:5174, база — временная, часы перематываются запросом `POST /api/dev/clock` с `{"iso": "2026-10-27T12:00:00+03:00"}` (с `"sleep": true` — как будто компьютер спал). Ярлыки из его настроек создаются во временной папке, а не на рабочем столе.

## Структура

```
engine/   движок расписания: чистая логика + тесты
server/   локальный сервер: база, Google Календарь, фоновые проверки
web/      интерфейс
docs/     методология, план, решения, инструкции
```
