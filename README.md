# Мой университет

Личный сервис для планирования самообучения: дисциплины, семестровое расписание с учётом Google Календаря, занятия с Помодоро, итоги и статистика. Работает локально на твоём ПК.

## Запуск

Нужен Node.js 24 или новее. Один раз:

```bash
npm install
npm run app:install
```

На рабочем столе появится ярлык «Мой университет», а сервис будет сам открываться на «Сегодня» при входе в Windows. Ярлык запускает сервер в фоне (без окна), если он ещё не работает, и открывает http://localhost:4100 в браузере. Напоминаний и уведомлений нет.

Автозапуск и ярлык включаются и выключаются в «Настройках» → «Запуск». Без автозапуска: `npm run app:install -- --no-autostart`.

Для разработки — `npm run dev` (интерфейс на http://localhost:5173 с горячей перезагрузкой). Перед этим останови фоновый сервис: `npm run app:stop`.

## Команды

| Команда                 | Что делает                                        |
| ----------------------- | ------------------------------------------------- |
| `npm run app`           | открывает сервис (запустит сервер, если нужно)    |
| `npm run app:stop`      | останавливает сервер, работающий в фоне           |
| `npm run app:install`   | ярлык на рабочем столе и автозапуск с Windows     |
| `npm run app:uninstall` | убирает ярлык и автозапуск                        |
| `npm run dev`           | режим разработки: сервер и интерфейс              |
| `npm run check`         | линтер, форматирование, проверка типов, все тесты |
| `npm test`              | только тесты                                      |
| `npm run check:env`     | проверяет ключи Google в `.env`, не показывая их  |
| `npm run format`        | выравнивает форматирование кода                   |
| `npm run simulate`      | печатает расписание тестовых сценариев таблицей   |

Свои дисциплины и календарь можно прогнать через симулятор: скопируй [engine/sim/semester.example.json](engine/sim/semester.example.json), поправь и запусти:

```bash
npm run simulate -- --file engine/sim/semester.example.json
```

Флаг `--details` печатает все занятия семестра.

## Как пользоваться

Открой ярлык «Мой университет». При первом запуске — мастер: время для учёбы и неудобное время, Google Календарь, дисциплины (с целью и метриками), семестр. Дальше — вкладки «Сегодня» (занятие с таймером Помодоро и итог), «Расписание», «Решения» (вопросы сервиса), «Дисциплины», «Семестр», «Статистика», «Настройки».

Особые случаи:

- **Компьютер уснул или выключился во время занятия** — таймер встаёт на паузу с того момента, время сна в учёбу не идёт. Если ты занимался по книге, нажми «Я занимался — засчитать». Пока идёт занятие и открыта его страница, экран не гаснет.
- **Закрыл браузер** — занятие продолжается, открой ярлык снова. Если время занятия вышло, а страница так и не открылась, таймер останавливается на конце занятия, а не считает до утра.
- **Другой часовой пояс на компьютере** (поездка) — расписание остаётся в поясе из настроек, сверху появляется подсказка, сколько там сейчас.

Если что-то не запускается — журнал сервера лежит в `data/logs/server.log`. После обновления кода интерфейс пересоберётся сам при следующем запуске ярлыка; если сервер уже работает — `npm run app:stop`, потом снова ярлык.

## Тестовый экземпляр

Чтобы проверить интерфейс, не трогая настоящую базу и Google:

```bash
node scripts/test-instance.mjs
```

Интерфейс — http://localhost:5174, база — временная, часы перематываются запросом `POST /api/dev/clock` с `{"iso": "2026-10-27T12:00:00+03:00"}` (с `"sleep": true` — как будто компьютер спал). Ярлыки из его настроек создаются во временной папке, а не на рабочем столе.

## Структура

```
engine/   движок расписания: чистая логика + тесты
server/   локальный сервер: база, Google Календарь, фоновые проверки
web/      интерфейс
docs/     методология, план, решения, инструкции
```
