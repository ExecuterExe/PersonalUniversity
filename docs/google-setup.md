# Подключение Google Календаря

Делается один раз, примерно 10 минут. Названия пунктов в Google Cloud иногда немного меняются — ориентируйся по смыслу.

> **Важно:** Client Secret — это пароль приложения. Не отправляй его в чат и никому не показывай. Ты сам вписываешь его в файл `.env` на своём ПК.

## 1. Создать проект

1. Открой [console.cloud.google.com](https://console.cloud.google.com) и войди тем Google-аккаунтом, чей календарь будешь использовать.
2. Вверху слева нажми на выбор проекта → **New project** (Создать проект).
3. Название: `Moy Universitet` → **Create**.
4. Убедись, что вверху выбран именно этот проект.

## 2. Включить Google Calendar API

1. Меню → **APIs & Services** → **Library** (Библиотека).
2. Найди **Google Calendar API** → **Enable** (Включить).

## 3. Настроить экран входа

1. Меню → **APIs & Services** → **OAuth consent screen** (откроется раздел **Google Auth Platform**) → **Get started**.
2. **App information:** имя приложения — `Мой университет`, email поддержки — твой.
3. **Audience:** выбери **External** (для обычного Gmail-аккаунта другого варианта нет).
4. **Contact information:** твой email.
5. Согласись с правилами → **Create**.

## 4. Добавить себя в тестовые пользователи

Приложение остаётся в режиме **Testing**, публиковать его не нужно. Для публикации Google требует публичный сайт с домашней страницей и политикой конфиденциальности — у сервиса на твоём ПК его нет.

1. Проверь **Google Auth Platform** → **Branding**:
   - **App name** — `Мой университет` (если не примет кириллицу — `Moy Universitet`);
   - **User support email** — твой;
   - **Developer contact information** → **Email addresses** — твой;
   - **App logo не загружай** — с логотипом Google потребует проверку приложения;
   - поля **App domain** и **Authorized domains** оставь пустыми;
   - если что-то менял — внизу **Save**.
2. Открой **Google Auth Platform** → **Audience** → **Test users** → **Add users**.
3. Впиши Gmail, чей календарь будешь подключать → **Save**.

Что это значит на практике: в режиме Testing Google выдаёт доступ на 7 дней. Раз в неделю сервис попросит «Войти заново» — один клик, данные и расписание не теряются.

## 5. Создать ключи (OAuth-клиент)

1. В **Google Auth Platform** открой **Clients** → **Create client**.
2. **Application type:** `Web application`.
3. **Name:** `Мой университет (локально)`.
4. **Authorized redirect URIs** → **Add URI** → вставь ровно:

   ```
   http://localhost:4100/auth/google/callback
   ```

5. **Create**.
6. Появится окно с **Client ID** и **Client secret**. Сразу нажми **Download JSON** или скопируй оба значения — секрет Google показывает только один раз.

## 6. Вписать ключи в `.env`

1. Открой файл `.env` в корне проекта (`C:\Users\PC\Documents\Работа\OrganizeUniversity\.env`) в любом редакторе, например в Блокноте.
2. Заполни две строки:

   ```
   GOOGLE_CLIENT_ID=<твой Client ID>
   GOOGLE_CLIENT_SECRET=<твой Client secret>
   ```

3. Сохрани файл.
4. Проверь в терминале в папке проекта:

   ```bash
   npm run check:env
   ```

   Должно появиться «Ключи Google на месте». Если нет — команда скажет, что именно не так. Сами ключи она не показывает.

## 7. Подключить календарь к сервису

1. Запусти сервис (`npm run dev`).
2. Открой в **обычном браузере** (Chrome и т. п.) адрес `http://localhost:5173/auth/google` — или нажми «подключить Google Календарь» на главной странице сервиса.
3. Войди в тот Google-аккаунт, который добавил в тестовые пользователи.
4. Google покажет «Google не проверил это приложение» — для личного приложения это нормально: **Продолжить**.
5. Отметь все три разрешения: видеть события, видеть список календарей, создавать свой календарь и события в нём.
6. Браузер вернётся на сервис, и там будет «Google: подключён».

Что сервис будет делать: читать занятость из твоих календарей и записывать занятия **только** в отдельный календарь «Мой университет», без напоминаний. Он появится, когда ты подтвердишь первый семестр. Раз в 7 дней сервис попросит войти заново.
